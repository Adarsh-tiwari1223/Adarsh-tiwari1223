## 👋 Welcome! Who Am I?

I am a **Software Quality Assurance Engineer** based in India. 

In simple terms: **I make sure websites, applications, and business software work smoothly, accurately, and without bugs before real customers use them.**

Every time developers build a new feature or change code, errors can happen—buttons can stop working, calculations can fail, or pages can freeze. Instead of manually clicking through hundreds of screens every single time, **I write automated test programs that thoroughly test the entire application in minutes**, catching bugs early and helping engineering teams ship high-quality software with confidence.

---

## 💼 What I Do (In Plain English)

* **Automated Website Testing:** I build programs using **Python and Playwright** that act like real users—opening browsers, filling out forms, logging in, navigating complex menus, and verifying that every button and workflow behaves properly.
* **API & Data Testing:** When a mobile app or website sends data to a server (like submitting a payment or updating an address), I test the background data pipelines using tools like **Postman** to ensure information arrives securely, quickly, and accurately.
* **Database Verification:** I write **SQL queries** directly against company databases to confirm that user actions (like booking a flight or onboarding an employee) are saved correctly and permanently behind the scenes.
* **Manual & Exploratory Testing:** Before automating, I analyze business requirements, explore user journeys, find hidden edge cases, and report issues clearly so developers can fix them quickly.
